Process simulation, freelance

For engineers, start-ups, researchers and student teams who need a model that is right and explained.

Steady-state and dynamic models

Flowsheets in AVEVA Process Simulation, with Aspen HYSYS and MATLAB/Simulink where they fit: mass and energy balances, reactors, separations, adsorption cycles.

  • Model built, converged and documented
  • Hand checks of the key balances
  • Model file plus a short report

Control loops and tuning

PID loop design on a dynamic model: plant gains from first principles, SIMC tuning, and tests against upsets and set point changes.

  • Tuning values with the working shown
  • Before and after trends
  • Performance figures such as IAE

Python automation and data

Python scripts that drive simulations: case studies, logging to a database, live dashboards and machine-learning surrogate models.

  • Runs your cases while you sleep
  • Clean data and plots
  • Code you can keep and rerun

Heat integration

  • Composite curves and targets
  • Exchanger network proposal
