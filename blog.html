November 2026 · Control and digital twins

Closing a PI loop around a dynamic AVEVA model from Python

The hard part was not the controller. It was getting a steady starting point: the model drifted when switched to Dynamics, so I added an initialisation run that holds the plant until inflow and outflow match, then saves that state as the snapshot every run starts from. With that in place, the SIMC-tuned PI cut the peak level error from 6.5 cm to 0.8 cm.

2026 · Graduation Project II

A 960 °C warning hidden in the case-study data

While training a surrogate model on 363 Power-to-Methane simulation cases, some first-reactor outlet temperatures reached 925–960 °C, far above the 620 °C catalyst limit. Tracing it back showed the recycle split drives the exotherm, so the recycle loop needs tight control.
